# OGEA-103 Combined — Mock Exams

Ce dossier contient **6 examens blancs complets** pour simuler l'examen TOGAF Enterprise Architecture Combined (OGEA-103).

## Format simulé

Chaque mock contient deux sections :

### Part 1 — Foundation / OGEA-101

- 40 QCM
- 60 minutes
- closed book
- seuil visé : 60 %
- pondération reproduite :
  - Concepts : 8
  - Introduction to the ADM : 14
  - Introduction to ADM Techniques : 6
  - Introduction to Applying the ADM : 4
  - Architecture Governance : 3
  - Architecture Content : 5

### Part 2 — Practitioner / OGEA-102

- 8 scénarios
- 90 minutes
- open book
- scoring pédagogique 5 / 3 / 1 / 0
- seuil visé : 60 %
- les huit grands domaines du syllabus sont représentés dans chaque mock.

## Règle Combined

Pour simuler correctement OGEA-103, traite les deux parties séparément et exige un score de passage dans **chaque section**. Ne compense pas un échec Part 1 par un bon score Part 2.

## Fichiers

- `mock-01-exam.md` à `mock-06-exam.md` : sujets sans réponses
- `corrections/mock-01-correction.md` à `corrections/mock-06-correction.md` : corrections et scoring

## Méthode recommandée

1. Chronométrer 60 minutes pour Part 1.
2. Fermer le cours et les notes pendant Part 1.
3. Faire une pause courte.
4. Chronométrer 90 minutes pour Part 2.
5. Utiliser les références TOGAF seulement pendant Part 2.
6. Corriger séparément chaque section.
7. Noter les erreurs par domaine.
8. Revenir aux chapitres et banques de questions correspondants.

## Important

Tous les items de ces mocks sont **originaux et pédagogiques**. Ils imitent le format public de l'examen mais ne reproduisent aucune question officielle ni brain dump.
