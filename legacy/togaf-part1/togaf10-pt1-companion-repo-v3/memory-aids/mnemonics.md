# Aides mémoire

## Baseline / Target / Transition
- Baseline = aujourd’hui
- Target = demain visé
- Transition = le chemin utile

## Deliverable / Artifact / Building Block
- Deliverable = ce qu’on remet
- Artifact = ce qu’on montre ou décrit
- Building Block = ce qu’on réutilise

## Governance / Project Management
- Governance = cadre, arbitrage, conformité
- Project Management = exécution, planning, coût
