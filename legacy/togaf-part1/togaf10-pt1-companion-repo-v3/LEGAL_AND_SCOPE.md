# Cadre d’usage

Ce dépôt a été créé comme **support d’étude original**.

## Règle de base

Le dépôt :

- s’inspire du **plan public** du cours ciblé ;
- reformule les notions avec ses propres synthèses ;
- ajoute des exercices et questions-réponses originaux.

Le dépôt **ne reproduit pas** :

- les vidéos ;
- les transcripts ;
- les questions officielles exactes ;
- les examens blancs du formateur ;
- des copies substantielles de documents protégés.

## Bon usage

Ce dépôt est utile pour :

- préparer le cours ;
- prendre des notes ;
- réviser ;
- compléter par les guides officiels TOGAF ;
- bâtir une base personnelle durable dans Git.
