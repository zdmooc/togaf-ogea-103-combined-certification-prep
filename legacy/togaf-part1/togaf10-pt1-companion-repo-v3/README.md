# TOGAF 10 Pt1 — Dépôt compagnon de préparation

Ce dépôt est un **compagnon d’étude** en français pour préparer un cours de type :

- **Cours architecture d'entreprise complet TOGAF édition 10 Pt1**

Il est conçu pour t’aider à :

- suivre le plan du cours de manière structurée ;
- reformuler les notions en langage simple ;
- mémoriser les concepts-clés ;
- t’entraîner avec des questions-réponses originales ;
- faire le pont entre TOGAF et des cas concrets d’architecture.

## Ce dépôt contient

- un **plan détaillé** du cours ;
- des **notes de cours reformulées** par chapitre ;
- un **glossaire** TOGAF Part 1 ;
- des **tableaux comparatifs** des notions fréquemment confondues ;
- des **quiz** et **questions-réponses originales** ;
- des **mini-cas pratiques** ;
- un **plan de révision** ;
- des **trackers** de progression.

## Ce dépôt ne contient pas

- les vidéos du cours ;
- les quiz officiels du formateur ;
- les examens blancs officiels ou copiés ;
- des extraits longs ou des transcriptions du contenu protégé.

## Utilisation recommandée

1. Lire `docs/00-course-map.md`
2. Suivre les notes de cours dans l’ordre
3. Faire un quiz après chaque chapitre
4. Reporter les erreurs dans `trackers/error-log.md`
5. Réviser la synthèse dans `docs/09-synthese-express.md`

## Résultat attendu

À la fin de ce dépôt, tu dois être capable de :

- expliquer les fondations de TOGAF en français simple ;
- reconnaître les notions du syllabus Part 1 ;
- distinguer les concepts souvent confondus ;
- répondre à des questions de niveau Foundation ;
- relier TOGAF à un contexte réel de transformation SI.
