# Chapitre 7 — Cadre de contenu détaillé

## Objectif
Éviter les confusions de niveau entre ce qu’on remet, ce qu’on décrit et ce qu’on réutilise.

## À retenir
- deliverable = livrable formel remis
- artifact = contenu descriptif
- building block = brique réutilisable

## Exemple simple
Un dossier de migration est un deliverable.
Il contient des artifacts comme une matrice de dépendances et un diagramme cible.
Il peut décrire des building blocks comme un cluster standard, un socle IAM ou un pattern d’exposition.

## Piège majeur
Tout appeler “livrable”.

## Exercice
Classe ces objets :
- dossier d’architecture
- matrice
- service IAM standard
- diagramme
- pattern de plateforme
