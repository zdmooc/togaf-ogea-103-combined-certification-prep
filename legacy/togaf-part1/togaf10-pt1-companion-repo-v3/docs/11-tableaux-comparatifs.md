# Tableaux comparatifs

## 1. Deliverable / Artifact / Building Block

| Notion | Idée simple | Exemple |
|---|---|---|
| Deliverable | Livrable formel remis | Dossier d’architecture |
| Artifact | Élément de description | Matrice, catalogue, diagramme |
| Building Block | Brique réutilisable | Service IAM standard |

## 2. Baseline / Target / Transition

| Notion | Idée simple |
|---|---|
| Baseline | Existant |
| Target | Cible |
| Transition | Étape intermédiaire |

## 3. Governance / Project Management

| Notion | Rôle principal |
|---|---|
| Architecture Governance | Cohérence, conformité, arbitrage, décisions |
| Project Management | Planning, coût, ressources, exécution |

## 4. Principle / Requirement / Constraint

| Notion | Rôle |
|---|---|
| Principle | Guide de décision |
| Requirement | Besoin à satisfaire |
| Constraint | Limite imposée |

## 5. Vision / Solution détaillée

| Notion | But |
|---|---|
| Vision | Donner la direction et l’adhésion |
| Solution détaillée | Décrire précisément une réalisation |
