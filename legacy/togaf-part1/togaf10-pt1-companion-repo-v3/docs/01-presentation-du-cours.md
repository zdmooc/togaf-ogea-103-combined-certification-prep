# Présentation du cours

## Ce que ce type de cours cherche à faire

Un cours TOGAF Part 1 sérieux doit normalement te donner :

- une vue d’ensemble du standard ;
- le vocabulaire essentiel ;
- une compréhension claire de l’ADM ;
- une lecture simple de la gouvernance ;
- une compréhension du contenu d’architecture ;
- une préparation au format Foundation / Part 1.

## Ce que tu dois chercher en l’écoutant

Pendant le cours, cherche surtout :

- les **définitions courtes** ;
- les **différences** entre notions proches ;
- les **enchaînements logiques** ;
- les **liens avec la réalité** ;
- les **erreurs fréquentes**.

## Réflexe utile

Ne cherche pas à mémoriser TOGAF comme une récitation.
Cherche à répondre à ces 5 questions :

1. Pourquoi l’architecture d’entreprise existe ?
2. Que cherche à produire l’ADM ?
3. Comment TOGAF structure la progression ?
4. Comment l’architecture est-elle gouvernée ?
5. Quels contenus produit-on réellement ?
