# Cas 03 — IAM / SSO

## Contexte
Une entreprise veut centraliser l’authentification de plusieurs applications.

## Questions
1. Donne 3 stakeholders.
2. Donne 2 principles plausibles.
3. Donne 1 deliverable.
4. Donne 2 artifacts.
5. Donne 2 building blocks.

## Exemples de réponse
- stakeholders : sécurité, utilisateurs, exploitation
- principles : authentification centralisée ; traçabilité par défaut
- deliverable : dossier de cadrage SSO
- artifacts : cartographie applicative, matrice des rôles
- building blocks : IdP ; reverse proxy / passerelle d’authentification
