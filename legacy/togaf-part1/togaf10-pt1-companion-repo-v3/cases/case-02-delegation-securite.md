# Cas 02 — Dérogation sécurité

## Contexte
Une équipe demande une exception à un principe de sécurité pour respecter un jalon de livraison.

## Questions
1. Pourquoi ce n’est pas seulement un sujet projet ?
2. Pourquoi la gouvernance d’architecture doit intervenir ?
3. Que faut-il tracer ?
4. Quel risque si rien n’est tracé ?

## Réponses attendues
- il s’agit d’un écart à une règle structurante ;
- la gouvernance arbitre et encadre ;
- justification, durée, risque, plan de remédiation ;
- sinon l’exception devient la norme implicite.
