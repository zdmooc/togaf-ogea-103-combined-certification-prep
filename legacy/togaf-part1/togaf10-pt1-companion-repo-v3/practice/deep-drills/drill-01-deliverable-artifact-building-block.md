# Drill 01 — Deliverable / Artifact / Building Block

## Objectif
Éliminer une confusion majeure de TOGAF Part 1.

## Exercice 1
Définis chaque notion en une phrase.

## Exercice 2
Pour chacun de ces objets, classe-le :
- dossier d’architecture
- matrice applications / environnements
- service IAM standard
- diagramme de flux
- pattern de plateforme cible

## Exercice 3
Sur un cas “migration VM -> Kubernetes”, propose :
- 2 deliverables
- 4 artifacts
- 3 building blocks

## Réflexe final
Un deliverable contient des artifacts.
Les artifacts peuvent décrire des building blocks.
