## Format d'examen de référence — vérifié 2026-09-06

### OGEA-101 / Part 1

- 40 questions
- 60 minutes
- 60% pour réussir
- répartition publique : **8 Concepts / 14 ADM / 6 ADM Techniques / 4 Applying ADM / 3 Governance / 5 Architecture Content**

### OGEA-102 / Part 2

- 8 scénarios
- 90 minutes
- 60% pour réussir
- open book
- scoring : **5 / 3 / 1 / 0**

Le détail et les liens officiels sont dans `14-official-sources/`.

## Méthode pédagogique

Les chapitres cherchent à répondre à :

**WHY → WHAT → WHEN → WHO → HOW → INPUTS → STEPS → OUTPUTS → RELATIONSHIPS → EXAM TRAPS → REAL EXAMPLE → MAYABANK → QUESTIONS → ENGLISH**

Foundation est traité comme **knowledge/comprehension** ; Practitioner comme **application/analysis**.

## Cas fil rouge

**MayaBank** est une banque fictive permettant de relier TOGAF à une transformation réaliste : paiements, données, applications, plateforme, sécurité, migration, gouvernance et changement.

Les technologies utilisées dans les exemples — OpenShift, APIs, event streaming, GitOps, observability, etc. — ne sont pas des prescriptions TOGAF.

## Questions et examens blancs

Les 300 QCM, 60 scénarios et 6 mocks sont des contenus pédagogiques originaux. Ils ne reproduisent ni questions officielles, ni brain dumps, ni barèmes confidentiels.

Les mocks reproduisent les caractéristiques publiques du format mais ne prétendent pas avoir la même difficulté psychométrique que l'examen réel.

## Langue

Le cours est principalement en français, avec conservation des termes TOGAF officiels en anglais. `13-english-for-architects/` prépare également l'expression orale et les entretiens d'architecture.
