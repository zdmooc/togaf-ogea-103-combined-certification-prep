## Integrated application

`08-mayabank-case-study/` applies the full chain:

**Context → Preliminary → A → B → C Data → C Application → D → E → F → G → H → Requirements → Complete Roadmap**.

This case is intentionally fictional and is used to connect TOGAF concepts to realistic architecture work.

- 8 Practitioner scenarios;
- separate corrections and section scoring.
