# 16 QCM ciblés — tous les livrables TOGAF X2202 Foundation 7.3

Exercices pédagogiques originaux. Choisir un seul livrable. Les 16 notions correspondent à l'énumération du syllabus X2202 §3.1.7 ; les corrections sont dans le fichier séparé.

## D01 — Request for Architecture Work

Une direction métier souhaite lancer une étude d'architecture sur la modernisation de ses virements. Avant la Vision et le cadrage convenu, quel livrable formalise cette sollicitation initiale ?

A. Statement of Architecture Work

B. Request for Architecture Work

C. Architecture Contract

D. Compliance Assessment

## D02 — Statement of Architecture Work

A. Architecture Requirements Specification

B. Architecture Roadmap

C. Communications Plan

D. Statement of Architecture Work

## D03 — Architecture Vision

D. Compliance Assessment
