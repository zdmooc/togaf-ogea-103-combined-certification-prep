# OGEA-101 Foundation Question Bank — 300 questions

## Purpose

Cette banque contient **300 questions originales** de préparation au TOGAF Enterprise Architecture Part 1 (OGEA-101). Elle n'utilise ni questions officielles copiées, ni brain dumps.

Chaque question contient :

- quatre choix A/B/C/D ;
- une réponse correcte ;
- une explication ;
- une justification courte des distracteurs ;
- un mapping vers le thème du syllabus.

## Méthode d'utilisation

1. Répondre sans regarder la correction.
2. Expliquer oralement pourquoi les trois autres réponses sont moins bonnes.
3. Noter le concept faible.
4. Revenir au chapitre de cours correspondant.
5. Refaire la question 48 à 72 heures plus tard.
