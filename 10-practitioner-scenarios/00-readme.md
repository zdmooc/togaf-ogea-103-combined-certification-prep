# OGEA-102 Practitioner Scenario Bank — 60 scénarios

## Purpose

Cette banque contient **60 scénarios originaux** pour préparer le TOGAF Enterprise Architecture Part 2 (OGEA-102) et la Section 2 de l’examen OGEA-103 Combined.

Elle n’utilise ni questions officielles copiées, ni brain dumps.

Chaque scénario contient :

- un contexte réaliste ;
- une question « meilleure action TOGAF » ;
- quatre réponses plausibles ;
- un scoring pédagogique **5 / 3 / 1 / 0** ;
- une explication du meilleur choix ;
- une explication de la hiérarchie des autres choix ;
- un mapping vers le domaine du syllabus.

## Format officiel de référence

Au 6 septembre 2026, The Open Group indique pour OGEA-102 :

- **8 questions scenario-based multiple choice** ;
- **90 minutes** ;
- **open book** ;
- **60 %** pour réussir ;
- scoring gradient : **5 / 3 / 1 / 0** ;
- une seule réponse sélectionnée par question.

Les grands domaines officiels sont :

1. Context for Enterprise Architecture
2. Stakeholder Management
3. Phase A: The Starting Point
4. Architecture Development — Phases B, C, D
5. Implementing the Architecture — Phases E, F, G
6. Architecture Change Management — Phase H
7. Requirements Management
8. Supporting the ADM Work

## Méthode d’entraînement

Pour chaque scénario :

1. lire le contexte avant les réponses ;
2. identifier la phase ou le problème ADM dominant ;
3. repérer stakeholders, concerns, requirements, governance et maturité du travail ;
4. éliminer les réponses prématurées, trop techniques ou hors séquence ;
5. choisir la meilleure réponse ;
6. seulement ensuite regarder le scoring pédagogique ;
7. expliquer oralement pourquoi le choix à 5 points est meilleur que celui à 3 points.

## Règle importante

Le scoring de cette banque est **pédagogique et original**. Il imite le principe officiel 5/3/1/0 mais ne reproduit aucun item ni barème confidentiel de l’examen réel.
