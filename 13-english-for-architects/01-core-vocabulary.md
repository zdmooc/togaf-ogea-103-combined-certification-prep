## 3. Phrases pour décrire l’existant

- `The current architecture is fragmented.`
- `The landscape contains several overlapping applications.`
- `There are multiple point-to-point integrations.`
- `The current platform relies heavily on batch processing.`
- `Operational visibility is limited.`
- `Ownership is unclear.`
- `The current solution creates strong coupling.`
- `The main limitation is scalability.`
- `The current model increases operational risk.`

## 4. Phrases pour décrire la cible

- `The target architecture introduces clear service boundaries.`
- `The target state reduces unnecessary coupling.`
- `The architecture standardizes APIs and event contracts.`
- `Data ownership becomes explicit.`
- `Observability is built into the platform.`
- `The target improves resilience and operability.`
- `The design supports incremental migration.`

## 5. Phrases pour expliquer une décision

- `We selected this option because...`
- `The decision was driven by...`
- `The main reason is...`
- `This option provides a better balance between...`
- `We rejected the alternative because...`
- `The key trade-off is...`
- `This decision reduces risk but increases...`
- `The choice is aligned with the following principle...`

## 6. Phrases pour ne pas être bloqué

Quand un mot manque :

- `Let me rephrase that.`
- `What I mean is...`
- `In other words...`
- `The important point is...`
- `I do not remember the exact term, but the idea is...`

Pour demander une précision :

- `Could you clarify what you mean by target state?`
- `Are you asking about the architecture or the implementation?`
- `Do you mean the current environment or the future platform?`
- `Should I focus on the technical architecture or the transformation approach?`

## 7. Faux amis / erreurs fréquentes

- `actual` = réel, pas actuel → utiliser `current` pour actuel.
- `eventually` = finalement, pas éventuellement → `possibly` ou `potentially`.
- `delay` = retard/délai ; `deadline` = échéance.
- `support` peut signifier soutien ou support technique selon contexte.
- `formation` n’est pas formation professionnelle → souvent `training`.
- `architecture dossier` n’est pas naturel → `architecture document`, `architecture package` ou `architecture deliverable`.

## 8. Mini drill

Dire à voix haute sans lire après trois répétitions :

> The current architecture is fragmented. We first identified the business drivers and stakeholder concerns. We then defined the target architecture, analyzed the gaps, and grouped the required changes into work packages. The migration is incremental because business continuity is critical.

## 10. Test oral

Répondre en moins de 30 secondes :

**What is the difference between a baseline and a target architecture?**

Réponse modèle :

> The baseline describes the relevant current state. The target architecture describes the desired future state. The gap analysis identifies what must change between the two, and those gaps later influence work packages and the migration roadmap.
